# StudentApp

**Lab objective:** Create a class component, create multiple components, render a
component.

## What it does
A "Student Management Portal" with three **class components** under
`src/Components/`:
- `Home.js` — "Welcome to the Home page of Student Management Portal"
- `About.js` — "Welcome to the About page of the Student Management Portal"
- `Contact.js` — "Welcome to the Contact page of the Student Management Portal"

All three are rendered together from `App.js`.

## Run
```bash
npm install
npm start
```
Open `http://localhost:3000`.
