# scorecalculatorapp

**Lab objective:** Create a function component, apply style to components, render a
component.

## What it does
`CalculateScore` is a **function component** (`src/components/CalculateScore.js`)
that accepts `Name`, `School`, `total`, and `goal` as props, calculates the average
score, and displays student details. Styling is provided via
`src/Stylesheets/mystyle.css`.

`App.js` invokes it with sample data (`Steeve`, `DNV Public School`, `284`, `3`).

## Run
```bash
npm install
npm start
```
Open `http://localhost:3000`.
