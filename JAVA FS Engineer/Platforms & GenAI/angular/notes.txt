Hands-On 1, Task 1 - Notes on generated project files
=======================================================

angular.json
  The Angular CLI's workspace configuration file. Defines project(s), build/serve/test
  targets, file paths, styles, assets, and budget thresholds used by the CLI builders.

tsconfig.json
  The base TypeScript compiler configuration shared across the whole workspace
  (strict mode, target ECMAScript version, module resolution, Angular compiler options).

tsconfig.app.json
  Extends tsconfig.json specifically for the application build - points at src/main.ts
  as the entry file and excludes spec files from the app bundle.

package.json
  Lists npm dependencies/devDependencies (Angular packages, NgRx, RxJS, testing tools)
  and defines CLI scripts (start, build, test).

src/main.ts
  The application's entry point. Bootstraps the standalone root component
  (AppComponent) using bootstrapApplication() with the app-wide providers in
  app.config.ts - the modern Angular 17+/20 approach (no AppModule required).

src/app/app.config.ts (replaces app.module.ts in standalone mode)
  Declares application-wide providers: the router, HttpClient with interceptors,
  and the NgRx store/effects/devtools. This file plays the role app.module.ts used
  to play in NgModule-based Angular apps.

src/app/app.component.ts
  The root component. Hosts the persistent header and the <router-outlet> where
  routed page components are rendered.

src/index.html
  The single HTML page of the SPA. Contains the <app-root> element that Angular
  bootstraps into, and loads the compiled JS bundles at runtime.

Angular CLI budgets (angular.json > architect > build > configurations > production)
  maximumWarning: the bundle size threshold above which the CLI prints a build warning
  but still succeeds.
  maximumError: the bundle size threshold above which the CLI FAILS the production
  build outright - forces the team to actively address bloat before shipping.

Note: This project uses Angular's standalone component API (default since Angular 17,
continued in Angular 20), so there is no app.module.ts - app.config.ts and
app.routes.ts serve the equivalent purpose.
